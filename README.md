# МЕТА Справочники Архитектора

Интерактивные справочники для проектирования многоквартирных домов:
- 🏗️ Технические помещения МКД
- 🔌 Парковка электромобилей
- 🅿️ Полы автостоянки

---

## 🚀 Быстрый старт

### Вариант 1: Локально (без интернета)
1. **Скачай все файлы** из папки
2. Открой `index-meta.html` в браузере (двойной клик)
3. Нажимай вкладки и переходи между справочниками

### Вариант 2: На GitHub Pages (онлайн сайт)

#### **Для Windows:**
1. Установи [Git](https://git-scm.com/download/win)
2. Скачай все файлы в одну папку
3. **Запусти `deploy.bat`** (двойной клик)
4. Введи свои GitHub учетные данные (если попросит)
5. ✅ Готово! Сайт будет на `https://Meta-Platforma.github.io/meta-guides/`

#### **Для Mac/Linux:**
```bash
# Перейди в папку с файлами
cd /path/to/files

# Запусти скрипт
chmod +x deploy.sh
./deploy.sh
```

## 🖼️ Как добавлять изображения

После загрузки на GitHub можешь добавлять изображения:

1. Открой репо: https://github.com/Meta-Platforma/meta-guides
2. Нажми **Add file** → **Upload files**
3. Перетащи изображения в папку `images/`
4. Коммитни изменения

Для вставки изображений в HTML используй:
```html
<img src="images/название-файла.jpg" alt="Описание">
```
